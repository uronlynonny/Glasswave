Every 30 minutes a small program on GitHub makes the same requests the app makes: same YouTube library version, same settings, signed out. Then it checks that the replies still contain what the app reads. When something breaks or recovers you get an ntfy alert. The bars show the last week, newest on the right. Couldn't test means YouTube asked GitHub's server to prove it isn't a bot. That's about the test server, not the people using the app. Signed-in library syncing isn't tested (it needs an account), but it uses the same YouTube replies as the checks above.
